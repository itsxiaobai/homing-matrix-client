# Homing UI 線框與元件規格

> **草案，待人類設計定稿。** 本檔只描述畫面結構、導覽、元件階層與資料流，
> 不定義配色／字型／間距／動效（那些由人類定稿後記入 `DESIGN.md`）。
> 以純文字線框呈現，可直接用 Android Studio（或任何文字編輯器）開啟修改。

## 1. 畫面清單與導覽

```text
啟動/登入 → 首次設定 → 主殼 (MainShell)
                         ├─ [聊天室] RoomsScreen      （首頁）
                         ├─ [聯絡人] ContactsScreen   （好友/群組/公開聊天室）
                         └─ [通話]   CallLogScreen
                              │
                              ├→ ChatScreen（聊天室）
                              │    ├→ ImagePreviewScreen（圖片全屏）
                              │    ├→ RoomInfoScreen（聊天室資訊）
                              │    └→ LiveKitCallScreen（通話）
                              ├→ SettingsBody（左上頭像面板）
                              └→ 各子頁（外觀/通知/装置/ Emergency… ）
```

断点：視窗寬度 <600dp＝底部膠囊列；≥600dp＝NavigationRail 側欄。

## 3. 元件階層（以 ChatScreen 為例）
```text
ChatScreen
├─ AppBar（返回／房名／通話選單／搜尋／更多）
├─ 公告橫幅 AnnouncementBanner（pinnedEventIds 自動抓）
├─ ListView.builder（列計畫 chat_row_plan）
│   └─ _messageRow
│       ├─ 收回灰框（isRedacted）
│       ├─ 回覆引言 _ReplyQuote（可點跳轉／可隱藏）
│       └─ 依型別：文字／圖片／貼圖／檔案／語音／投票／通話 chip
├─ 表情回覆覆蓋層
└─ 輸入列
    ├─ 開關：＋/叉 · 相機 · 相簿 · 無聲 · Markdown(本則)
    ├─ TextField + 表情
    └─ Mic / 送出
```

## 4. 狀態與資料流
- **訊息**：SDK timeline → `ChatMessageView`（純資料）→ `_messageRow`（無樣式骨架）
- **收回**：官方 `m.room.redaction` → `event.redacted` → 灰框
- **公告**：`room.pinnedEventIds`（Matrix 標準 state）→ 取最新文字訊息 → 首頁橫幅
- **Markdown**：本則開關 → 送出時寫 `dev.homing.markdown` 旗標 → 收訊端僅帶旗標才渲染
- **另存**：SAF 選資料夾 → Uri 存 kv → 下載直接寫入；未設定先要求選擇
- **主題／圖示**：`AppIcons` 槽位（可被主題包覆換）；Compound icon 為固定 SVG（不覆換）
